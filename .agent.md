# Filson Shell Development Agent

## Project Context
This agent specializes in developing the Filson Unix shell, a C implementation of a Unix shell with built-in commands and environment variable support.

## Coding Style Requirements

### Mandatory Coding Conventions
- **Language**: C (C99 standard)
- **Code Style**: KNR (Kernighan & Ritchie) with FreeBSD conventions
- **Comments**: None - code must be self-documenting
- **Indentation**: Tabs (FreeBSD standard, 8 spaces wide)
- **Brace Style**: Opening brace on same line as function declaration

### Function Definition Format
```c
return_type
function_name(param_type param1, param_type param2)
{
	local_var_declarations;
	
	function_body;
	return result;
}
```

### Variable Declaration Style
- All variables declared at the start of function/block
- Use short, descriptive names
- No inline variable declarations

### File Structure
- Include headers at top
- Function declarations
- Macro definitions
- Function implementations
- Main function (if applicable)

## Build System
- Uses Makefile
- Default target: Filson executable
- Targets: `build`, `test`, `test-builtins`, `test-env`, `run`, `clean`

## Testing Requirements
- Write unit tests for all new features
- Tests in separate files with `_test` or `test_` prefix
- All tests must pass before committing

## Git Workflow
- Meaningful commit messages
- Commit after completing features
- Keep history clean

## When Making Changes
1. Apply KNR/FreeBSD style to ALL modified code
2. Remove any comments
3. Ensure self-documenting variable names
4. Run `make test` before committing
5. Update git repository with descriptive messages

## Do NOT
- Add explanatory comments
- Use non-standard C extensions
- Deviate from FreeBSD coding style
- Skip test execution before commits
